# 土壤肥力综合评价初步研究 算法
> 版本：V3.1，2026.9.26修订（修复边界与权重逻辑问题）
> 作者：Guoqiang Li @ HNAAS
> E-Mail: hnagri@qq.com

## 一、算法来源
算法摘自：**土壤肥力综合评价初步研究**，浙江大学学报，1999，25（4）：378-382

## 二、版本修订说明（V3.1 更新内容）
1. 隶属函数增加参数合法性检查并向量化，提升批量计算效率，规避非法输入报错；
2. 权重计算改为取相关系数绝对值，**避免出现负权重**，符合土壤肥力评价物理意义；
3. 新增变量数量校验与常数列检查，提前识别异常输入数据集，减少模型运行错误。

## 三、项目文件说明
| 文件名称 | 功能描述 |
| ---- | ---- |
| MainRun.R | 程序主入口，运行脚本，一键执行评价流程 |
| main.R | 整体流程调度 |
| UserDefinedFunction.R | 自定义函数库（隶属函数、权重计算、综合得分等核心算法） |
| config.R | 土壤养分指标的最大值、最小值。综合评价指标的分级阈值 |
| SoilFertilityData.csv | 原始土壤采样输入数据 |
| SoilResult.csv | 模型输出：土壤肥力评价结果表 |

## 四、运行环境
- R语言 >= 4.0
- 依赖基础包：`stats`（相关系数计算，R自带无需额外安装）

## 五、使用步骤
1. 准备土壤样本数据，按照`SoilFertilityData.csv`格式整理输入；
2. 在`config.R`中修改评价指标等配置参数；
3. 运行`MainRun.R`启动程序；
4. 计算完成后，结果自动输出至`SoilResult.csv`。

## 六、算法简要原理
1. **隶属度计算**：根据指标属性（升型/降型）调用隶属函数，将各项肥力指标归一化至0~1区间；增加参数校验，支持向量批量运算。
2. **权重求解**：基于指标间相关系数，取绝对值归一化得到各指标权重，消除负权重干扰。
3. **综合肥力指数IFI**：加权求和各指标隶属度，得到土壤肥力综合评价得分。

## 七、注意事项
1. 输入数据不能包含常数列（全部样本值相同的指标），程序内置检查；
2. 输入指标参数需在隶属函数有效区间内，程序会做合法性校验；
3. `SoilResult.csv`为程序输出结果文件，一般不纳入git版本管理，可加入.gitignore。
